# Verifica della prima versione

Data: 22 ottobre 2026. Python utilizzato: 3.14 su Windows.

- 38 test offline passati, senza chiamate cloud o comandi a dispositivi nei test.
- CLI diagnostica avviabile; nessuna dipendenza Python esterna necessaria.
- Riacquisiti base APK e quattro split della versione 1.5.13 (47).
  Hash identici alla precedente acquisizione verificata con apksigner.
- Toolchain REA/JDK/JADX e materiali di analisi copiati nella cartella privata
  della copia di lavoro, esclusi dalla selezione dell'archivio pubblico.
- Nessun setter, custom component, automazione HA o aggiornamento firmware
  installato o eseguito. Nessuna pubblicazione GitHub effettuata.

Il client cloud ha completato login e letture reali: un impianto, due circuiti
con dettagli coerenti e programmi settimanali presenti. Credenziali e cookie
non sono stati salvati; lo snapshot resta privato. Le misure non hanno un
timestamp proprio sufficiente a provarne la freschezza.

Scaricato dall'endpoint ufficiale relativo al proprio G1 il pacchetto
applicativo versione 140 (circa 5,5 MB). File estratti e quattro sorgenti
analizzati staticamente con REA, senza eseguirli. Nessuna installazione.

Il client LAN è sperimentale e
non è stato verificato con una API key G1. L'apertura di una porta TCP non
dimostra la compatibilità applicativa.

Il prototipo locale HA 0.2.0 è predisposto ma non installato. Sintassi Python
e JSON verificati, adattatore testato offline; runtime HA non verificato.
Analisi aggiuntiva REA completata su autenticazione, file locali ed export
della cache. Diagnostica shell di sola lettura predisposta, non eseguita sul G1.

Questo stato descrive la versione 0.2.0; nuove sessioni reali richiederanno
un aggiornamento esplicito della matrice di compatibilità, senza pubblicare
le risposte private integrali.
